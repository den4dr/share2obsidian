**【信頼性レベル凡例】**:
- 🔵 **青信号**: 要件定義書・ヒアリングで明確に必要と判明したタスク
- 🟡 **黄信号**: 要件定義書から妥当に推測されるタスク
- 🔴 **赤信号**: 推測による予防的タスク（実装時に不要と判明する可能性あり）

## 必須（実装開始前に完了が必要）

- [ ] **動作確認用のLLM APIキー（OpenAI互換Chat Completions形式）の準備** 🔵 *REQ-002/REQ-402より*
  - OpenAI互換のChat Completions APIを提供するサービス（例: OpenAI本家、または互換プロキシ/ローカルLLMサーバー等）のAPIキーとエンドポイントURLを用意してください
  - 実装中の単体テストはモックで代替可能ですが、E2E動作確認には実際のAPIキーが必要です
  - 関連要件: REQ-002, REQ-004, REQ-402

## 推奨（実装中に用意できればOK）

- [ ] **暗号化ストレージ用ライブラリ（例: androidx.security-crypto）の選定** 🟡 *REQ-401/NFR-101より*
  - `gradle/libs.versions.toml` への追加が必要になる見込みです。プロジェクトの他の依存関係との互換性を事前に確認してください
  - 必要になるフェーズ: 設計・実装フェーズ（永続化基盤）
  - 関連要件: REQ-401, NFR-101

- [ ] **HTTPクライアントライブラリ（Ktor Client / Retrofit+OkHttp等）の選定** 🟡 *REQ-402より*
  - 現状プロジェクトにHTTP通信ライブラリが未導入のため、新規追加が必要です
  - 必要になるフェーズ: 設計・実装フェーズ
  - 関連要件: REQ-402

## 確認事項（判断が必要）

- [ ] **メモ内容を外部LLM APIへ送信することについてのプライバシー上の確認** 🟡 *機能の性質上の一般的な注意事項*
  - 本機能はユーザーが共有した元コンテンツ（ProcessedContent、プライベートな内容を含み得る）を、ユーザー自身が設定した外部LLM APIサービスへ送信します。個人利用アプリのため法務確認は必須ではない可能性がありますが、README等にその旨を明記するかどうかの判断が必要です
  - 関連要件: REQ-002
