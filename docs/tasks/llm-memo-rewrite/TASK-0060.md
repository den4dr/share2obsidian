### 2. LlmRewriteRepositoryImpl のリクエスト構築 🔵

**信頼性**: 🔵 *api-endpoints.md「リクエスト仕様」より*

```kotlin
val response: ChatCompletionResponseDto = httpClient.post(settings.endpointUrl) {
    header(HttpHeaders.Authorization, "Bearer ${settings.apiKey}")
    contentType(ContentType.Application.Json)
    setBody(
        ChatCompletionRequestDto(
            model = settings.model,
            messages = listOf(
                ChatMessageDto(role = "system", content = prompt),
                ChatMessageDto(role = "user", content = content),
            ),
        )
    )
}.body()
```

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/data/llm/LlmRewriteRepositoryImpl.kt`

### 3. system/userロールのメッセージ順序 🟡

**信頼性**: 🟡 *OpenAI Chat Completionsの一般的慣習からの妥当な推測。api-endpoints.md「リクエスト仕様」表 messages[0].role/messages[1].role 参照*

`messages[0]` を `role = "system"`（テンプレートの `bodyLlmPrompt` または タグ提案用固定プロンプト）、`messages[1]` を `role = "user"`（`sourceContent`）として送信する。

### 4. 例外の LlmRewriteResult へのマッピング 🔵

**信頼性**: 🔵 *api-endpoints.md「エラーレスポンスとマッピング」表より*

```kotlin
try {
    // リクエスト実行
} catch (e: HttpRequestTimeoutException) {
    LlmRewriteResult.Failure.Timeout(R.string.error_llm_timeout)
} catch (e: ClientRequestException) {
    if (e.response.status.value == 401 || e.response.status.value == 403) {
        LlmRewriteResult.Failure.AuthError(R.string.error_llm_auth)
    } else {
        LlmRewriteResult.Failure.Unknown(R.string.error_llm_unknown)
    }
} catch (e: IOException) {
    LlmRewriteResult.Failure.NetworkError(R.string.error_llm_network)
} catch (e: Exception) {
    LlmRewriteResult.Failure.Unknown(R.string.error_llm_unknown)
}
```

例外オブジェクト自体（APIキーを含むリクエストヘッダ情報等を含みうる）はログに出力しない（NFR-102）。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/data/llm/LlmRewriteRepositoryImpl.kt`

### 5. 空応答・不正レスポンスの判定 🟡

**信頼性**: 🟡 *EDGE-004（空応答時の扱いは直接確認していない）*

レスポンスの `choices` が空、または `choices[0].message.content` が `null`/空文字の場合は `LlmRewriteResult.Failure.EmptyOrInvalidResponse(R.string.error_llm_empty_response)` を返す。

```kotlin
val text = response.choices.firstOrNull()?.message?.content
if (text.isNullOrEmpty()) {
    LlmRewriteResult.Failure.EmptyOrInvalidResponse(R.string.error_llm_empty_response)
} else {
    LlmRewriteResult.Success(text)
}
```

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/data/llm/LlmRewriteRepositoryImpl.kt`
