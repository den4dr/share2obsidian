## 実装詳細

### 1. LLM設定セクションの追加 🔵

**信頼性**: 🔵 *既存 `SettingsScreen.kt` の vault/folder `OutlinedTextField` パターンより*

既存のvault/folder入力欄と同様のパターンで、`HorizontalDivider` で区切ったLLM設定用セクションを `Column` 内に追加する。

```kotlin
HorizontalDivider()

OutlinedTextField(
    value = uiState.llmEndpointUrl,
    onValueChange = viewModel::updateLlmEndpointUrl,
    label = { Text(stringResource(R.string.settings_llm_endpoint_label)) },
    modifier = Modifier.fillMaxWidth().testTag("settings_llm_endpoint_field"),
)

OutlinedTextField(
    value = uiState.llmApiKey,
    onValueChange = viewModel::updateLlmApiKey,
    label = { Text(stringResource(R.string.settings_llm_apikey_label)) },
    visualTransformation = PasswordVisualTransformation(),
    modifier = Modifier.fillMaxWidth().testTag("settings_llm_apikey_field"),
)

OutlinedTextField(
    value = uiState.llmModel,
    onValueChange = viewModel::updateLlmModel,
    label = { Text(stringResource(R.string.settings_llm_model_label)) },
    modifier = Modifier.fillMaxWidth().testTag("settings_llm_model_field"),
)
```

testTagは `settings_llm_endpoint_field`, `settings_llm_apikey_field`, `settings_llm_model_field` とする。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/SettingsScreen.kt`

### 2. apiKey欄のマスク表示 🟡

**信頼性**: 🟡 *既存実装にない新規UI要素のため妥当な推測。機微情報の一般的なUIパターン（`PasswordVisualTransformation`）を採用*

`visualTransformation = PasswordVisualTransformation()` を適用し、入力内容が画面上に平文表示されないようにする。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/SettingsScreen.kt`

### 3. onValueChangeによるViewModel呼び出し 🔵

**信頼性**: 🔵 *REQ-004・既存vault/folder入力欄の即時保存パターンより*

各欄の `onValueChange` で `viewModel.updateLlmEndpointUrl()` / `viewModel.updateLlmApiKey()` / `viewModel.updateLlmModel()` を呼び出し、既存のvault/folderと同様に入力変更のたびに即時保存する。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/SettingsScreen.kt`
