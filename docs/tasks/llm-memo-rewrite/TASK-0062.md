## 実装詳細

### 1. `sourceContent`退避の追加 🔵

**信頼性**: 🔵 *architecture.md「ProcessedContent保持設計」より*

現状の `MainActivity.kt`（該当箇所）:

```kotlin
val processed = /* ContentProcessorの結果 */
val defaultTemplate = templateRepository.getDefaultTemplate()
val noteSettings = noteSettingsRepository.getSettings().first()
val config = TemplateApplicator.buildConfig(noteSettings)
val resolvedBody = TemplateApplicator.buildBody(defaultTemplate, processed.body)
val customFields = TemplateApplicator.buildCustomFields(defaultTemplate, processed)
viewModel.initialize(processed.copy(body = resolvedBody), config, customFields)
```

変更後は、`TemplateApplicator.buildBody()` 呼び出しの直前で `processed.body`（テンプレート適用前の値）を `sourceContent` として退避する。

```kotlin
val processed = /* ContentProcessorの結果 */
val defaultTemplate = templateRepository.getDefaultTemplate()
val noteSettings = noteSettingsRepository.getSettings().first()
val config = TemplateApplicator.buildConfig(noteSettings)
val sourceContent = processed.body  // 🔵 REQ-406: テンプレート適用前の元コンテンツを退避
val bodyLlmPrompt = defaultTemplate?.bodyLlmPrompt.orEmpty()  // 🔵 REQ-002
val resolvedBody = TemplateApplicator.buildBody(defaultTemplate, processed.body)
val customFields = TemplateApplicator.buildCustomFields(defaultTemplate, processed)
viewModel.initialize(
    processed = processed.copy(body = resolvedBody),
    config = config,
    customFields = customFields,
    sourceContent = sourceContent,
    bodyLlmPrompt = bodyLlmPrompt,
)
```

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/MainActivity.kt`

### 2. `bodyLlmPrompt`算出の追加 🔵

**信頼性**: 🔵 *architecture.md「新規追加コンポーネント」・REQ-101, REQ-102より*

`defaultTemplate`が`null`の場合（デフォルトテンプレート未設定時）も考慮し、`orEmpty()`で空文字にフォールバックする。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/MainActivity.kt`

## 単体テスト要件

### テストケース1: sourceContentがテンプレート解決前の値であること 🔵

**信頼性**: 🔵 *architecture.md「ProcessedContent保持設計」・REQ-406より*

**Given**: `ACTION_SEND`インテントで`EXTRA_TEXT`を含む共有が行われ、本文にプレースホルダを含むデフォルトテンプレートが設定されている
**When**: `MainActivity`がRobolectricで起動される
**Then**: `viewModel.initialize()`に渡される`sourceContent`引数が`processed.body`（テンプレート適用前の値）そのものであり、同時に渡される`processed`（`resolvedBody`を含む）の`body`とは異なる値になっている

### テストケース2: bodyLlmPromptがdefaultTemplateのbodyLlmPromptと一致すること 🔵

**信頼性**: 🔵 *REQ-101・architecture.md「新規追加コンポーネント」より*

**Given**: `bodyLlmPrompt = "要約してください"`が設定されたデフォルトテンプレートが存在する
**When**: `MainActivity`がRobolectricで起動される
**Then**: `viewModel.initialize()`に渡される`bodyLlmPrompt`引数が`"要約してください"`と一致する

### テストケース3: defaultTemplateがnullの場合bodyLlmPromptが空文字になること 🔵

**信頼性**: 🔵 *`orEmpty()`によるnullフォールバック・REQ-102より*

**Given**: デフォルトテンプレートが未設定（`templateRepository.getDefaultTemplate()`が`null`を返す）
**When**: `MainActivity`がRobolectricで起動される
**Then**: `viewModel.initialize()`に渡される`bodyLlmPrompt`引数が空文字`""`になり、例外は発生しない
