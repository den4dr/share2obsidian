## 単体テスト要件

### テストケース1: Template の copy() で bodyLlmPrompt のみ変更できること 🔵

**信頼性**: 🔵 *data class の基本仕様・REQ-101より*

**Given**: `bodyLlmPrompt = ""` の `Template` インスタンスが存在する
**When**: `template.copy(bodyLlmPrompt = "要約してください")` を呼び出す
**Then**: 返された `Template` の `bodyLlmPrompt` が `"要約してください"` であり、他のプロパティ（`name`, `body`, `fields`, `isDefault` 等）は変更前と同一である

### テストケース2: FieldValueSource.entries に LLM が含まれること 🔵

**信頼性**: 🔵 *REQ-303より*

**Given**: `FieldValueSource` enum が定義されている
**When**: `FieldValueSource.entries` を参照する
**Then**: `FieldValueSource.LLM` が含まれ、`FieldValueSource.valueOf("LLM")` が例外なく `FieldValueSource.LLM` を返す

### テストケース3: TemplateField の copy() で llmPrompt のみ変更できること 🔵

**信頼性**: 🔵 *data class の基本仕様・REQ-104より*

**Given**: `llmPrompt = ""` の `TemplateField` インスタンスが存在する
**When**: `field.copy(llmPrompt = "タイトルを生成してください")` を呼び出す
**Then**: 返された `TemplateField` の `llmPrompt` が `"タイトルを生成してください"` であり、他のプロパティ（`key`, `valueSource`, `valueType` 等）は変更前と同一である

### テストケース4: 既存デフォルト値の後方互換性 🔵

**信頼性**: 🔵 *既存コンストラクタ呼び出し（引数指定なし）への影響最小化・NFR-001相当の既存パターン踏襲より*

**Given**: 既存コードと同様に `bodyLlmPrompt`/`llmPrompt` を指定せずに `Template`/`TemplateField` を生成する
**When**: インスタンスを生成する
**Then**: `bodyLlmPrompt`/`llmPrompt` はそれぞれデフォルト値 `""` になり、コンパイルエラーは発生しない
