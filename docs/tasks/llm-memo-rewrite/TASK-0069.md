### 2. タグ入力欄付近への「タグを提案」ボタン追加 🔵

**信頼性**: 🔵 *REQ-103, REQ-201パターン踏襲（本文リライトボタンと同様のローディング表示パターン）*

```kotlin
OutlinedTextField(
    value = formState.tagsText,
    onValueChange = viewModel::updateTagsText,
    label = { Text(stringResource(R.string.label_tags)) },
    modifier = Modifier.fillMaxWidth(),
)
Button(
    onClick = { viewModel.suggestTags() },
    enabled = !formState.isSuggestingTags,
) {
    if (formState.isSuggestingTags) {
        CircularProgressIndicator(
            modifier = Modifier.size(16.dp),
            strokeWidth = 2.dp,
        )
    } else {
        Text(stringResource(R.string.button_suggest_tags))
    }
}
```

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/EditScreen.kt`

## UI/UX要件

### ローディング状態 🔵

**信頼性**: 🔵 *本文リライトボタン（TASK-0065）と同様のローディング表示パターンを踏襲*

`isSuggestingTags` が `true` の間、ボタン内のテキストを `CircularProgressIndicator` に置き換え、ボタンを非活性化する。本文リライトボタンの `isRewritingBody` 中の表示パターンと同一の実装方針とする。

### エラー表示 🔵

**信頼性**: 🔵 *本文リライトと同じerrorEvents購読の仕組みを再利用するため追加実装は不要*

エラー表示は本文リライトと同じ `errorEvents` 購読の仕組みを再利用する。TASK-0065で実装済みの `LaunchedEffect(viewModel.errorEvents) { ... }` が `rewriteBody()`/`suggestTags()` 両方の失敗イベントを処理するため、本タスクでのToast表示に関する追加実装は不要。
