## タスク概要

LLM APIをHTTPで呼び出すためのKtor Client（CIOエンジン）とkotlinx-serialization、APIキーを暗号化保存するためのandroidx-security-cryptoを新規導入する。現状プロジェクトにHTTPクライアント・JSONライブラリ・暗号化ストレージライブラリは一切導入されていない（既存の`jsoup`はHTML静的パース専用でネットワークI/Oを行わない）。本タスクはPhase 1の最初のタスクであり、後続の全LLM関連実装タスクの前提となる。

## 実装詳細

### 1. version catalog への追加 🔵

**信頼性**: 🔵 *architecture.md「新規追加コンポーネント」表・「アーキテクチャパターン」（Ktor Client CIOエンジン・kotlinx-serialization・androidx.security-crypto を新規導入）より*

`gradle/libs.versions.toml` に以下を追加する。

**実装ファイル**: `gradle/libs.versions.toml`

```toml
[versions]
# 既存に追加
ktor = "3.0.x"                    # 導入時点の安定版を確認して設定する
kotlinxSerialization = "1.7.x"     # kotlin = "2.2.10" と互換のある安定版
androidxSecurityCrypto = "1.1.x"

[libraries]
# 既存に追加
ktor-client-core = { group = "io.ktor", name = "ktor-client-core", version.ref = "ktor" }
ktor-client-cio = { group = "io.ktor", name = "ktor-client-cio", version.ref = "ktor" }
ktor-client-content-negotiation = { group = "io.ktor", name = "ktor-client-content-negotiation", version.ref = "ktor" }
ktor-serialization-kotlinx-json = { group = "io.ktor", name = "ktor-serialization-kotlinx-json", version.ref = "ktor" }
kotlinx-serialization-json = { group = "org.jetbrains.kotlinx", name = "kotlinx-serialization-json", version.ref = "kotlinxSerialization" }
androidx-security-crypto = { group = "androidx.security", name = "security-crypto", version.ref = "androidxSecurityCrypto" }

[plugins]
# 既存に追加
kotlin-serialization = { id = "org.jetbrains.kotlin.plugin.serialization", version.ref = "kotlin" }
```

### 2. build.gradle.kts への追加 🔵

**信頼性**: 🔵 *既存 `app/build.gradle.kts` の plugins/dependencies ブロック構成、architecture.md「アーキテクチャパターン」より*

**実装ファイル**: `app/build.gradle.kts`

```kotlin
plugins {
    // 既存に追加
    alias(libs.plugins.kotlin.serialization)
}

dependencies {
    // 既存に追加

    implementation(libs.ktor.client.content.negotiation)
    implementation(libs.ktor.serialization.kotlinx.json)
    implementation(libs.kotlinx.serialization.json)
    implementation(libs.androidx.security.crypto)
}
```
