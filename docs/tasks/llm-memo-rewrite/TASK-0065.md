## 実装詳細

### 1. 「メモを更改」ボタンの追加 🔵

**信頼性**: 🔵 *REQ-001, REQ-201より*

`EditScreen.kt`の`body_field`（`OutlinedTextField(..., modifier = Modifier.testTag("body_field"))`）付近に、以下のようなボタンを追加する。

```kotlin
Button(
    onClick = { viewModel.rewriteBody() },
    enabled = formState.rewriteBodyEnabled && !formState.isRewritingBody,
    modifier = Modifier.testTag("rewrite_body_button"),
) {
    if (formState.isRewritingBody) {
        CircularProgressIndicator(
            modifier = Modifier.size(16.dp),
            strokeWidth = 2.dp,
        )
    } else {
        Text(stringResource(R.string.button_rewrite_body))
    }
}
```

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/EditScreen.kt`

### 2. エラーToast表示の追加 🔵

**信頼性**: 🔵 *design-interview.md Q3・NFR-201より*

```kotlin
val context = LocalContext.current
LaunchedEffect(Unit) {
    viewModel.errorEvents.collectLatest { resId ->
        Toast.makeText(context, context.getString(resId), Toast.LENGTH_LONG).show()
    }
}
```

既存の`MainActivity.onSend`内の`ActivityNotFoundException`捕捉時のToastパターン（`Toast.makeText(this, getString(R.string.error_obsidian_not_installed), Toast.LENGTH_LONG).show()`）と同様のトーンを踏襲する。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/EditScreen.kt`

## UI/UX要件

### ローディング状態 🔵

**信頼性**: 🔵 *REQ-201より*

`isRewritingBody`中はボタン内に`CircularProgressIndicator`を表示し、ボタンを非活性化する。処理完了後は通常のテキストラベル表示に戻る。

### エラー表示 🔵

**信頼性**: 🔵 *NFR-201より*

`errorEvents`購読によるToast表示。メッセージは既存の日本語エラーパターン（`error_obsidian_not_installed`と同様のトーン）に沿った`error_llm_*`文字列リソース（TASK-0064で追加済み）を使用する。

### モバイル対応 🔵

**信頼性**: 🔵 *既存EditScreen実装より*

既存EditScreenのスクロール可能`Column`にボタンを追加するのみのため、追加のレイアウト対応は不要。

### アクセシビリティ 🟡

**信頼性**: 🟡（既存実装パターンからの妥当な推測。明示的なヒアリングはない）

ボタンには`stringResource(R.string.button_rewrite_body)`によるテキストラベルを設定し、スクリーンリーダーが読み上げ可能な状態を維持する。ローディング中もボタンのテキストコンテンツ（またはcontentDescription）が失われないよう配慮する。
