### 3. エラーメッセージの追加 🔵

**信頼性**: 🔵 *NFR-201・既存の`error_obsidian_not_installed` = 「Obsidian がインストールされていません」と同じ日本語トーンより*

```xml
<string name="error_llm_network">ネットワークに接続できませんでした</string>
<string name="error_llm_auth">LLM APIの認証に失敗しました。APIキーを確認してください</string>
<string name="error_llm_timeout">LLM APIの応答がタイムアウトしました</string>
<string name="error_llm_empty_response">LLM APIから有効な応答が得られませんでした</string>
<string name="error_llm_unknown">LLM APIの呼び出し中に不明なエラーが発生しました</string>
```

各文字列は `EDGE-001`（ネットワーク）、`EDGE-002`（認証）、`EDGE-003`（タイムアウト）、`EDGE-004`（空応答）にそれぞれ対応する。

**実装ファイル**: `app/src/main/res/values/strings.xml`
