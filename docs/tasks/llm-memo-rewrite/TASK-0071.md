## タスク概要

`TemplateEditScreen`に本文用LLMプロンプト入力欄を追加し、`FieldAddDialog`の値取得方法ラジオボタンに「LLM」を追加、選択時にフィールド用プロンプト入力欄を表示する。テンプレート保存時に`bodyLlmPrompt`/`llmPrompt`が正しく保存・復元されるよう`TemplateEditViewModel`を修正する。

### 7. `FieldAddDialog`への「LLM」選択肢追加 🔵

**信頼性**: 🔵 REQ-104, REQ-303

値取得方法のラジオボタンリスト（`listOf(FieldValueSource.FIXED to ..., FieldValueSource.HTML_META to ..., FieldValueSource.URL to ..., FieldValueSource.EMPTY to ...)`）に`FieldValueSource.LLM to stringResource(R.string.field_source_llm)`を追加する。`valueSource == FieldValueSource.LLM`が選択されている場合、`defaultValue`/`metaKey`入力欄と同様の位置にプロンプト入力用`OutlinedTextField`（`field_llm_prompt_label`）を表示する。`onAdd`時、`llmPrompt = if (valueSource == FieldValueSource.LLM) llmPromptInput else ""`を設定した`TemplateFieldEditState`を渡す。

**実装ファイル**: `app/src/main/java/com/den4dr/share2Obsidian/ui/template/TemplateEditScreen.kt`
